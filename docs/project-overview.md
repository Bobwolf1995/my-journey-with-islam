# نظرة عامة على المشروع

## اسم المشروع

رحلتي مع الإسلام

## وصف المشروع

"رحلتي مع الإسلام" منصة تعليمية إسلامية متكاملة تستهدف المسلم الجديد، وتساعده على التعلم خطوة بخطوة من خلال مسارات تعليمية، دورات، دروس، مهام، اختبارات، مرشدين، محادثات، مكتبة معرفة، أوسمة، رتب، ومجتمع تفاعلي.

المشروع يبدأ كتطبيق Android باستخدام Flutter، مع Backend API ولوحة إدارة لإدارة المحتوى والمستخدمين والدورات والطلبات والتقارير.

## الهدف الأساسي

تقديم تجربة تعليمية إسلامية سهلة، آمنة، منظمة، وهادئة للمسلم الجديد، مع متابعة تقدمه وربطه بمرشدين موثوقين عند الحاجة.

## ملاحظات تصميمية

- التطبيق عربي أولًا.
- الاتجاه من اليمين إلى اليسار RTL.
- الألوان الأساسية: أخضر داكن، أبيض، بيج فاتح، ذهبي هادئ.
- التصميم يجب أن يكون بسيطًا، راقيًا، وسهل الاستخدام.
- الواجهة يجب أن تشبه تطبيق موبايل حقيقي وليس صفحة ويب داخل تطبيق.
